What a check looks for

  • Hidden instructions. Text in a tool description that tells the agent to do something you did not ask for, or to hide it from you.
  • Tool shadowing. Descriptions that try to change how the agent uses your other tools.
  • Invisible characters. Zero-width text that a person reading the description cannot see.
  • Risky capabilities. Shell commands, dynamic code, reads of SSH or cloud credential files, calls to hard-coded addresses.

This directory does not list other people's projects. Checks run on what you paste, and nothing is stored.
