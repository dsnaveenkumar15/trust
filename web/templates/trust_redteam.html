How it works

  1. Static check

    Trust's rules and a map of what each tool can reach: files, network, shell.

  2. Analyst picks attacks

    Three to six known attack patterns, each tied to exact text in your tools.

  3. Victim agents

    A careful model and a small, cheap one each get fake tools, planted fake secrets and a harmless task; plain code checks what each did.

  4. Proof and fix

    Every success is re-run with the suspect text rewritten, to show the cause and test the fix.
